Title: Fast API to-do list demo

This fastapi application is meant to demonstrate the basics of how a fastapi application works. We will be using a scenario of building a basic to do list app.

TIP: Once you run the app, check out the documentation at:
http://localhost:8000/docs#/

Development plan:
Version 1: A basic api that does not connect to anything.
Version 2: Implement OpenAPI integration.
Version 3: Add unit testing
Version 4: Integrate with Cloud Firebase
Version 5: AWS Deployment with https
Version 6: Add users and authentication
